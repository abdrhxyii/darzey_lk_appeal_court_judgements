23.07.2014

Learned Senior State Counsel submits that the indictment in this case has already been served

on the accused on 15.07.2014.

Learned counsel for the petitioner submits that an application for bail had been made after filing

the indictment. However, that application has been refused by the learned High Court Judge. Since the

circumstances has now changed after this application had been made, learned counsel for the

Petitioner moves to withdraw this revision application reserving his right to file another application .

Learned Senior State Counsel has no objection to this application. Accordingly, the application for

withdrawal is allowed reserving the right to file a fresh application. Accordingly. this revision application

is dismissed.

Application dismissed.
